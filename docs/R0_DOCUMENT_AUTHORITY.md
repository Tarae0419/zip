## 문서별 지위

| 문서 | 지위 | 충돌 시 처리 |
| --- | --- | --- |
| `docs/PRD_V2.md` | 현재 제품 계약 | 사용자 최신 결정과 함께 최우선으로 갱신한다. |
| `docs/SPRINT_PLAN_V2.md` | 현재 실행 계획 | PRD2와 코드 검증 결과에 맞춰 상태를 갱신한다. |
| `docs/R0_*.md` | R0 증거·의사결정 기록 | PRD2를 바꾸지 않으며 근거와 미완료 게이트를 기록한다. |
| `docs/PRD.md` | V1 요구사항 기록 | V2와 충돌하면 적용하지 않는다. |
| `docs/SPRINT_PLAN.md` | V1 구현 이력 | 체크박스를 V2 완료로 승계하지 않는다. |
| `docs/FEATURE_SUMMARY.md` | 레거시 구현 탐색용 | 검증 전 현재 기능·완료 판정으로 사용하지 않는다. |
| `CLAUDE.md` | 저장소 작업 안내 | 제품 계약을 새로 정의하지 않고 PRD2로 연결한다. |

## 확인된 충돌과 결정

| 주제 | 레거시 또는 이전 문구 | 현재 결정 |
| --- | --- | --- |
| 기존 기능 완료 | V1 스프린트의 완료 체크 | 재설계·최적화·회귀를 다시 통과하기 전 PRD2 미완료 |
| 지도 공급자 | Kakao 지도·NAVER 앱 폴백 | 사용자 런타임은 TMAP 지도·경로만 사용 |
| 이동 시간 표시 | 하루 전체 거리·시간 합계 | 각 실제 경로 위 `도보 n분`만 표시하고 하루 총합은 미노출 |
| 한 수업인 날 | 연속 수업이 없으면 동선 없음 | TMAP 지도에 해당 수업 건물 핀과 정보를 표시 |
| TMAP 키 상태 | 공개 Vector 키 미설정 | Vercel 공개 키 설정과 프로덕션 지도 표시 확인 |
| F5 완료 | 지도 또는 API 응답 성공만으로 완료 | 출입구 수동 검수·쿼터 운영·F15 계약 회귀까지는 제한적 운영 |

새 사용자 결정이 기존 문구와 충돌하면 먼저 PRD2와 이 원장을 갱신한 뒤 구현·테스트·스프린트 상태를 맞춘다.
