## 1. 상태 정의

| 상태 | 판정 기준 |
| --- | --- |
| 사용 가능 | 현재 범위에서 출처와 사용 근거가 있으며 구현·검증에 사용할 수 있음 |
| 승인 대기 | 원본·키·담당자 승인·권한·검수 중 하나 이상이 없어 제품 완료에 사용할 수 없음 |
| 사용 불가 | 예시·추정·무허가이므로 공식 사실이나 제품 콘텐츠로 사용할 수 없음 |

사용 가능은 원문의 자유로운 재배포 허가를 뜻하지 않는다. 별도 허가가 없으면 구조화된 최소 정보와 공식 원문 링크만 사용한다.

## 3. 현재 지원 범위 판정

- 학사 계획의 검증 후보 범위는 현재 근거가 있는 전자공학부·컴퓨터인공지능학부 2024학번이다.
- 이는 최종 제품 범위 확정이 아니다. 학과 사무실 또는 학사 데이터 책임자의 승인 전까지 시연·검증 범위로만 취급한다.
- 공식 선수과목이 없으므로 현재 계획은 선수 순서를 공식 하드 제약으로 확정할 수 없다.
- 2026년 2개 학기만으로 장기 수강 추세나 예상 개설 학기를 단정할 수 없다.
- 외부 콘텐츠 기능 F9·F11·F13·F14는 G4 승인 전 데이터 준비 중 상태를 유지한다.
