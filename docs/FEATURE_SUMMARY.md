# 수강길잡이 — 주요 기능 정리 (PPT용)

> PPT 제작을 위한 요약 문서입니다. 상세 스펙은 `docs/PRD.md`, 진행 현황은 `docs/SPRINT_PLAN.md` 참고.

---

## 1. 한 줄 소개

**수강길잡이**는 대학생이 수강 과목을 탐색하고, 진로에 맞는 커리큘럼을 설계하는 과정을 돕는 AI 기반 수강 도우미입니다.

## 2. 문제 정의

기존 커뮤니티 서비스(예: 에브리타임)의 한계:

| 문제 | 수강길잡이의 해결 |
| --- | --- |
| 수강평이 텍스트로만 나열돼 종합 파악이 어려움 | 해시태그 통계 + AI 3~5문장 요약 |
| 과목명이 정확히 일치해야만 검색됨 | 과목명 + 학문분야 태그 통합검색 |
| 관심 진로 분야(예: 반도체) 관련 과목을 통합적으로 못 찾음 | 산업분야 키워드 검색 (AI 임베딩 기반 연관도 정렬) |
| 전공 요건 + 진로를 함께 고려한 커리큘럼 설계 도구가 없음 | AI 맞춤 커리큘럼 플래너 |

## 3. 핵심 기능 (F1~F4)

### F1. 수강평 해시태그 & AI 요약
- 정해진 9개 해시태그(꿀강의/과제많음/시험어려움 등) 중 선택해 리뷰 작성, AI가 리뷰 본문 기반 태그도 추천
- 리뷰 **5개 이상**부터 AI가 3~5문장 한글 요약 생성 (평점이 극단적으로 갈리면 "호불호가 갈려요" 같은 신호도 포함)
- 리뷰는 학수번호 기준으로 학기를 넘나들며 집계 — 학기가 바뀌어도 리뷰가 사라지지 않음
- 최소 어뷰징 필터링(같은 사용자 중복 등록 방지), **본인 리뷰는 직접 삭제 가능**

### F2. 분야 통합 검색
- 검색어 하나로 "과목명 일치" + "학문분야 태그 일치"를 별도 탭으로 동시에 보여줌
- 10대분류 × 66소분류 학문분야 태그 체계(동의어 사전 포함) — AI가 과목마다 자동 분류
- 검색 결과 정렬(관련도순/평점순/리뷰많은순)은 서버 재조회 없이 클라이언트에서 즉시 처리
- 학부전공 과목뿐 아니라 **교양 과목**도 검색 대상(2026-1/2학기, 361개 고유 과목)

### F3. 산업/진로 분야 키워드 검색
- "반도체", "AI" 같은 산업 키워드로 학과 경계를 넘어 관련 과목을 한 번에 검색
- OpenAI 임베딩 + pgvector 코사인 유사도로 과목-산업분야 연관도 점수화, 연관도순 정렬
- **산업분야 카테고리 11개**: 반도체 · AI·데이터사이언스 · 바이오·헬스케어 · 금융·핀테크 · 콘텐츠·미디어 · 에너지·환경 · 모빌리티·로보틱스 · 스마트시티·건설 · 교육·에듀테크 · 농식품·스마트팜 · 물류·유통

### F4. AI 맞춤 커리큘럼 설계
- 학과(회원가입 시 저장된 본인 학과 고정) + 복수전공/부전공(본인 학과 제외 전체 학과 중 선택) + 현재 학년·학기 + 기이수 학점 + 관심분야(다중 선택, 우선순위 순) 입력
- 전공필수 → 전공선택 요건 → 관심분야 매칭 순으로 학기별 추천, 선수과목 순서까지 고려한 배치
- **학년 적합도 반영**: 과목별 권장 학년을 확인해 2학년에게 4학년 과목을 앞당겨 추천하지 않음(단, 한 학년 선이수는 허용). 학기마다 "그 학년에 맞는 과목 우선 → 자리가 남으면 선이수" 2단계로 채워서, 특정 학기에만 과목이 몰리지 않고 전체 학기에 고르게 분산
- 추천 과목을 클릭 한 번으로 제외하고 즉시 재계산 가능
- 전공필수 배치를 포함한 전체 학기별 배치는 AI(gpt-4o-mini)가 1차로 설계하고, 서버가 졸업요건 완결성·선수과목 순서·학기당 학점상한을 검증·보정한다(위반 시 결정론적 로직으로 보정, AI 호출 실패 시 결정론적 로직으로 전체 대체) — 2026-07-31부터, `docs/SPRINT_PLAN.md` 오픈 이슈 로그 참고
- 참고용 데이터 안내: 현재 2개 학과(전자공학부·컴퓨터인공지능학부)만 지원, 그래프요건/선수과목은 예시 데이터

## 4. F5. 시간표 & 캠퍼스 이동동선 (PRD 범위 밖 추가 기능)

- 관심 과목을 장바구니에 담으면 **주간 시간표**를 자동 생성, 시간 겹침은 담기 전에 자동 감지해 차단
- 담은 과목의 요일별 이동 동선을 **카카오맵 실좌표 기반**으로 시각화 — 강의실 건물명을 카카오 로컬 API로 지오코딩해 실제 지도 위에 번호 순서대로 표시, 건물 간 이동시간은 직선거리로 추정
- 홈 화면에서 로그인한 사용자의 **소속 학과 기준 인기 과목**을 보여줌(최근 한 달 리뷰 증가량 + 최소 평점 기준)

## 5. 회원 시스템

- 학번 + `@jbnu.ac.kr` 이메일 인증(6자리 코드) + 비밀번호 기반 회원가입/로그인
- 개인정보 최소 수집 원칙에 따라 익명 식별자(anonId)를 세션 토큰으로 재사용 — 리뷰·커리큘럼 프로필 등 기존 로직과 매끄럽게 연결
- 로그인하지 않으면 서비스 전체 접근 불가(로그인/회원가입 페이지 제외)

## 6. 기술 스택

| 영역 | 기술 |
| --- | --- |
| 프레임워크 | Next.js (App Router), React 19, TypeScript |
| UI | shadcn/ui, Tailwind CSS v4 |
| DB | Neon Serverless Postgres + Drizzle ORM, pgvector(임베딩 검색) |
| AI | OpenAI `gpt-4o-mini`(요약·해시태그·추천사유), `text-embedding-3-small`(분야 연관도) |
| 지도 | 카카오맵 JS SDK + 카카오 로컬 API(지오코딩) |
| 배포 | Vercel (Git 연동 자동 배포) |

## 7. 차별점 요약

1. **리뷰를 읽지 않아도 파악 가능** — 해시태그 통계 + AI 요약
2. **검색어가 정확하지 않아도 발견 가능** — 학문분야 태그 + 산업분야 임베딩 검색
3. **단순 과목 나열이 아닌 "계획"을 제공** — 학년·선수과목·학점 요건을 고려한 학기별 커리큘럼
4. **시간표 넘어 동선까지** — 담은 과목의 실제 이동 동선을 지도로 시각화
