# 수강길잡이 V2 개발 스프린트 계획

> 기준: `docs/PRD_V2.md`. 기존 F1~F5 이력은 `docs/SPRINT_PLAN.md`에서 유지한다.

## 진행 원칙

- 1개 스프린트는 1주 기준이며 데이터 제공 일정에 따라 조정한다.
- 공식 데이터가 없는 기능은 AI로 추정하지 않고 `데이터 대기`로 둔다.
- 각 스프린트는 코드, 테스트, 출처·상태 UI까지 완료해야 종료한다.
- 선수과목·졸업요건·시간 충돌은 AI 이후 결정론적 로직으로 재검증한다.
