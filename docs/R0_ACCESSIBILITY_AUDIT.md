# R0 접근성 재현·개선 기록

| 항목 | 내용 |
| --- | --- |
| 기준일 | 2026-08-29 |
| 범위 | 공개·인증·검색·수강평·시간표·관리자 화면의 정적 코드 감사 |
| 기준 | [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines), WAI-ARIA 대화상자·탭 키보드 패턴 |
| 자동 검증 | `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm build` |

이 기록은 과거의 “접근성 완료” 표시를 재사용하지 않는다. 키보드·스크린리더·동작 줄이기·모바일 폭에서 다시 재현한
결함과 이번 R0에서 고친 범위를 구분한다. 실제 VoiceOver/TalkBack 기기 검증은 R15 전수 회귀에서 별도로 수행한다.

## 이번 R0에서 수정한 결함

| 재현 조건 | 기존 문제 | 수정·회귀 기준 |
| --- | --- | --- |
| 과목 추가, 과목 관리, 수강평 작성, 시간표 충돌 창에서 `Tab`/`Shift+Tab` 반복 | 포커스가 배경으로 빠지고 일부 창은 ESC·스크롤 잠금·종료 포커스 복귀가 없었다. | 네 수동 모달을 Base UI Dialog로 교체했다. 포커스 트랩, ESC/외부 클릭 닫기, 배경 비활성화·스크롤 잠금, 닫힌 뒤 기존 버튼 복귀를 공통 primitive가 담당한다. |
| 시간표 충돌 창 열기 | 경고를 열어도 포커스가 배경 버튼에 남았다. | `alertdialog`를 유지하고 “확인” 버튼을 초기 포커스로 지정했다. |
| 별점 없이 수강평 등록 | 오류가 시각적으로만 생기고 제출 버튼에 포커스가 남았다. | 오류를 `role=alert`로 공지하고 첫 별점 버튼으로 포커스를 옮기며 오류 설명을 별점 그룹에 연결했다. AI 태그 결과도 live status로 공지한다. |
| 640px 미만에서 주요 내비게이션을 화면낭독기로 탐색 | 텍스트는 숨고 아이콘도 장식 처리되어 링크 이름이 사라졌다. | 각 링크에 고정된 접근 가능한 이름과 내비게이션 레이블을 부여했다. |
| 키보드로 페이지 첫 포커스에서 본문 이동 | 모든 헤더 컨트롤을 반복 통과해야 했다. | 전역 “본문으로 건너뛰기” 링크와 각 주요 페이지의 `main-content` 대상을 연결했다. 로그인·회원가입도 `main` 랜드마크로 바꿨다. |
| 운영체제의 동작 줄이기 활성화 | 무한 반딧불 이동·날갯짓·광원 애니메이션이 계속됐다. | `prefers-reduced-motion: reduce`에서 모든 장식용 반딧불 애니메이션을 중단한다. |
| 375px 이하 회원가입 인증 화면 | 6개 OTP 입력칸이 카드 폭보다 넓어 잘렸다. | 고정 48px 행을 반응형 6열 그리드로 바꿨다. |
| 모바일 OTP 자동완성으로 6자리 일괄 입력 | 마지막 한 자리만 남았다. 빈 값 입력으로 현재 자리 삭제도 되지 않았다. | 다자리 자동완성·붙여넣기·모바일 삭제를 정규화하는 순수 로직과 단위 테스트를 추가했다. |
| iOS에서 인증·검색·수강평 입력 포커스 | 14px 입력 글꼴 때문에 브라우저가 화면을 확대할 수 있었다. | 수정한 모바일 입력은 16px을 사용하고 `sm` 이상에서 기존 14px로 돌아간다. |

## 후속 스프린트에서 재작업할 결함

| 우선순위 | 재현된 결함 | 주 재작업 |
| --- | --- | --- |
| 높음 | 리뷰 삭제 확인 UI가 원래 삭제 버튼을 제거해 포커스를 잃고, 삭제 실패도 공지하지 않는다. | R3 |
| 높음 | 관리자 편집·검색 입력 일부가 프로그램상 레이블이 없고 민감 변경에 확인·복구·감사 흐름이 부족하다. | R1·R2·R15 |
| 중간 | 검색 탭에 roving `tabIndex`, 좌우 방향키, `aria-controls`/`tabpanel` 연결이 없다. | R3 |
| 중간 | 공통 아이콘 버튼과 관리자 태그 삭제 등 일부 모바일 터치 영역이 44px보다 작다. | R15 |
| 중간 | 과목명·해시태그·리뷰·건물명에 긴 무공백 문자열을 넣으면 일부 카드가 가로로 넘친다. | R3·R7·R15 |
| 중간 | 공통 focus-visible 표현, 비동기 skeleton status, 오류 포커스 이동이 화면마다 일관되지 않다. | 각 기능 스프린트·R15 |
| 낮음 | TMAP 컨테이너의 지도 의미와 텍스트 경로 목록의 대체 콘텐츠 관계가 명시적이지 않다. | R7 |

## 수동 회귀 시나리오

1. 각 Dialog를 키보드로 열고 첫/마지막 포커스 항목에서 `Shift+Tab`/`Tab`을 반복해 배경으로 이탈하지 않는지 확인한다.
2. ESC, 닫기, 배경 클릭으로 닫은 뒤 대화상자를 연 컨트롤에 포커스가 돌아오는지 확인한다.
3. 320px·375px 폭에서 OTP 여섯 칸이 잘리지 않고, 문자 포함 붙여넣기와 운영체제 자동완성 결과가 정확히 여섯 자리인지 확인한다.
4. 동작 줄이기 활성화 후 랜딩 화면의 반딧불과 등장 애니메이션이 멈추는지 확인한다.
5. 화면낭독기에서 모바일 주요 내비게이션의 다섯 링크 이름, 수강평 오류, AI 태그 도착 상태를 확인한다.
